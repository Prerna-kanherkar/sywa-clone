# SYWA Consultancy - Engineering & MEP Services Website

A modern, responsive clone of **SYWA Consultancy** built with **Next.js 16**, **React 19**, and **Tailwind CSS v4**.

## ✨ Features
- **Dynamic Navbar**: Transparent sticky scroll header with glassmorphism, route highlighting, animated top notification bar with speech bubble, interactive multi-category Services mega-dropdown, and 9-dots quick appointment drawer.
- **Corporate MEP Showcase**: Detailed engineering consulting, staff resourcing, and training pages.
- **Interactive Forms & Inquiries**: Consultation request drawer with responsive validation and feedback.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile devices.
- **Netlify Ready**: Pre-configured with `netlify.toml` and `@netlify/plugin-nextjs` for zero-configuration deployments.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Locally
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
```

## 🌐 Deploy to Netlify
1. Connect this repository to [Netlify](https://app.netlify.com).
2. Netlify will auto-detect the `netlify.toml` file with:
   - **Build Command**: `npm run build`
   - **Publish Directory**: `.next`
   - **Runtime**: `@netlify/plugin-nextjs`
3. Click **Deploy Site**!
